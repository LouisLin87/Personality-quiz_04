# 獵魔士熊貓64型：自我探索V4

Demonward Panda 64: Self Explorer V4 · beta.9.3

這個目錄是 GitHub Pages 上傳用前端。將本目錄內的檔案放在儲存庫網站根目錄，保留 assets/ 的層級與檔名；入口是 index.html，不需要 Node 或前端套件安裝。上傳檔案與啟用 Pages 需由儲存庫擁有者自行進行，本次只準備檔案。

點擊音效使用使用者提供的 ui click-02.m4a。音效預解碼並於按下時觸發；作答頁精簡，主要結果放大、細節點開。同分時先顯示完整候選型號與中文名稱，第二個選項按回答內容可為 +1、0 或 −1，順序在續答時固定。支援點擊音效開關、先選答再勾選其他想法、按下一題保存、24 題起步、一次平手補題及自選完整 60 題。第四項仍是不計分出口，選填文字不自動加分。

已接上使用者核准的 Apps Script。開始時選擇「同意自動保存並開始」，完成各階段便自動寫入 V4_測驗紀錄，不必先建立私人找回碼；也可選擇僅在本機作答。舊結果可在結果頁同意補存。私人找回仍為另一個自選功能，資料存 V4_結果，舊 V4 分頁保留。找回碼請自行保管；補充原文仍須另行同意並手動保存。此檔案包不含接收器、私人資料、測試或憑證。Chrome HTTP 預覽已完成真實寫回與獨立客戶端找回，正式 Pages 與 LINE／Threads 實機仍待驗證。
