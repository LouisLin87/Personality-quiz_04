先答 24 題；資料足夠且精確平手的面向各補兩題、只補一輪，前段 24～36 題。之後可看結果或自行繼續至完整 60 題。題目不重複；中間回答表示兩側接近，第四項 skip 才是不適用或無法判斷。

把本資料夾內 39 個公開檔案上傳到既有 GitHub Pages 網站根層，保留 assets/ 層級。入口 index.html，不需安裝前端套件。legacy-v4-beta.9.3.html 保留原中文版的舊紀錄入口，必須一起上傳。請使用正式網址查看，勿以 file URL 測試。
