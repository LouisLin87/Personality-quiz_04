# 獵魔士熊貓64型：自我探索 V4

Demonward Panda 64: Self Explorer V4 · beta.9.4.2 · [English](README.en.md)

本版保留首頁「中文／English」切換。60 題題幹與專屬回答、不計分出口、選填補充、結果、階段選擇與私人存檔說明皆有日常英文。語言偏好會記住；作答中切換保留題號、答案與草稿。網址加 `?lang=en` 可直接打開英文。

結果頁新增「一鍵儲存結果圖」，在裝置端產生並下載PNG，並保留可長按／右鍵儲存的預覽。圖片含型態、六軸分數與最多三組「你可能擅長的事／可以留意的地方」；平手、近中線或資料不足不硬配特點。這些觀察可在結果頁自行展開。圖中不放找回碼、逐題答案或補充原文。

先答 24 題，資料足夠且精確平手的面向各補兩題，只補一輪，前段共 24～36 題。答完第 30 題會先顯示目前的作答傾向，可展開各面向分數並查看日常情境回想。中間回答表示兩側接近，第四項為不適用或無法判斷。

將上傳資料夾內的檔案與 assets/ 整個資料夾放到既有 GitHub Pages 發布目錄。index.html 與 assets/ 應位於同一層。同時上傳 legacy-v4-beta.9.3.html，以便查閱舊題本記錄。

開始測驗時須同意將完成摘要保存到 Google。沿用既有接收端。跨裝置取回結果及保存生活例子可使用 Google 私人存檔，文字保存需另行同意。

中英共用 beta.9.4 題庫 ID、題序、計分與資料格式；應用 beta.9.4.2，英文呈現 plain-en-1.0。語言是顯示偏好，不新增雲端語言欄位。本機延續原作答／摘要鍵，另用獨立語言偏好鍵；舊版單檔保留原鍵，不讀寫 V3。

供娛樂與自我探索參考。英文已逐題對照語意，但尚未進行雙語測量等值或真人試讀驗證，不宣稱因此提高準確率。
